## 使用方式

- 先完成 P0「課堂列表 → 課堂詳情 → 請假 → 提交成功 → 請假紀錄」。
- P0 為首批工作；P1 待相關規則確認後開始。以下為建議工序，非已批准排期。
- 勾選完成：將 `- [ ]` 改為 `- [x]`；完成前填寫成果或證據。
- 狀態可用：未開始、進行中、待確認、完成、不適用。不適用需註明原因。
- 業務規則由產品／營運確認；你主責視覺設計，與 UX／產品協作確認流程。
- Markdown 的狀態與進度需手動更新，不包含試算表下拉選單或自動統計。

### 各階段工作與交接

#### 01. 需求與素材盤點（P0）

- **設計師工作：** 收集現有 App 截圖、品牌、語言、平台限制；列出未知規則。
- **交付成果：** 需求摘要＋待確認清單
- **AI／Skill 用法：** 一般對話：摘要與找缺口
- **協作分工：** 你整理；產品／營運確認；工程提供限制
- **完成條件：** 資料可追溯；未知規則有負責人
- **成果連結／阻塞：** 待填

#### 02. 畫面與狀態清單（P0）

- **設計師工作：** 先定義課堂列表→詳情→請假→提交成功→紀錄。
- **交付成果：** 5 個主畫面＋狀態矩陣
- **AI／Skill 用法：** 一般對話：流程與狀態表
- **協作分工：** 你與 UX／產品共同確認
- **完成條件：** 每頁目的、欄位、操作、出口清楚
- **成果連結／阻塞：** 待填

#### 03. 低保真線框（P0）

- **設計師工作：** 確認資訊層級、多學生切換、表單順序及返回路徑。
- **交付成果：** 可討論的線框及流程連結
- **AI／Skill 用法：** visualize：快速互動草稿
- **協作分工：** 你設計；產品審流程；工程看可行性
- **完成條件：** 主路徑可走通；業務待定點有標記
- **成果連結／阻塞：** 待填

#### 04. 視覺方向（P0）

- **設計師工作：** 用課堂列表、請假表單各做兩個方向；沿用品牌限制。
- **交付成果：** 兩組高保真示範＋取捨說明
- **AI／Skill 用法：** imagegen：情緒板、插畫概念
- **協作分工：** 你定美術方向；品牌／產品確認
- **完成條件：** 選定字體、色彩、密度與圖像語言
- **成果連結／阻塞：** 待填

#### 05. 基礎元件（P0）

- **設計師工作：** 整理色彩、字級、間距、按鈕、欄位、卡片、狀態標籤。
- **交付成果：** UI 基礎規範＋元件狀態
- **AI／Skill 用法：** 一般對話：命名、token 與狀態檢查
- **協作分工：** 你主責；工程確認命名及實作
- **完成條件：** 同一元件可重用，狀態與規格齊備
- **成果連結／阻塞：** 待填

#### 06. 核心完整畫面（P0）

- **設計師工作：** 完成 5 頁與載入、空、失敗、停用、附件錯誤。
- **交付成果：** 高保真畫面＋點擊原型
- **AI／Skill 用法：** 一般對話：截圖評審及文案
- **協作分工：** 你主責；產品／營運核對狀態
- **完成條件：** 已收到申請不被誤寫成已批准
- **成果連結／阻塞：** 待填

#### 07. 評審與修正（P0）

- **設計師工作：** 請代表使用者操作；記錄卡點；與工程確認。
- **交付成果：** 問題清單、修正版、決策紀錄
- **AI／Skill 用法：** 一般對話：整理回饋、合併重複問題
- **協作分工：** 你主持；家長代表、產品、工程參與
- **完成條件：** 阻塞問題有處理結果或明確決策
- **成果連結／阻塞：** 待填

#### 08. 工程交接（P0）

- **設計師工作：** 整理尺寸、字級、元件、文案、資產、狀態與權限說明。
- **交付成果：** 交接規格＋素材＋版本連結
- **AI／Skill 用法：** documents：交接文件；Spreadsheets：追蹤
- **協作分工：** 你交付；前端／App 工程接收
- **完成條件：** 工程能指出每頁資料、操作和錯誤呈現
- **成果連結／阻塞：** 待填

#### 09. 開發後視覺驗收（P0）

- **設計師工作：** 比較實作與設計；檢查字體、間距、長文字、裝置與狀態。
- **交付成果：** 差異清單與修正確認
- **AI／Skill 用法：** 一般對話：兩張截圖逐項比較
- **協作分工：** 你核視覺；QA 核流程；工程修正
- **完成條件：** 核心畫面和錯誤狀態驗收完成
- **成果連結／阻塞：** 待填

#### 10. 延伸公告與付款（P0）

- **設計師工作：** 套用同一元件系統，完成公告、帳單、付款證明及核對狀態。
- **交付成果：** 第二批 P0 畫面
- **AI／Skill 用法：** 一般對話＋既有元件
- **協作分工：** 你主責；營運／財務確認；工程評估
- **完成條件：** 上傳證明不會誤顯示已付款
- **成果連結／阻塞：** 待填

#### 11. 功課、RSVP、補堂（P1）

- **設計師工作：** 待規則確認後，沿用 02–09 工序製作後續功能。
- **交付成果：** P1 畫面與驗收紀錄
- **AI／Skill 用法：** 一般對話＋visualize
- **協作分工：** 你與產品、教務、工程
- **完成條件：** VL、補堂資格及名額規則已確認
- **成果連結／阻塞：** 待填

## 3. AI 與 Skill 使用指南

以下依建立原工作表時，本對話提供的 skill／插件清單整理。一般對話已能處理摘要、文案與評審；按工作需要使用。

### 1. 需求整理｜一般 AI 對話

- **可用狀態：** 不需額外 skill
- **你先提供：** App Features＋Phase 1 文件
- **你要核對：** 檢查有否新增原文件沒有的規則

**可複製指令：**

```text
請只根據附件，列出 P0 畫面、使用者、資料欄位、狀態及待確認問題。每項標明來源；建議與已確認需求分開。
```

### 2. 流程與草稿｜visualize

- **可用狀態：** 本工作環境可用
- **你先提供：** 畫面清單＋已確認流程
- **你要核對：** 用於快速討論；仍需整理正式設計檔

**可複製指令：**

```text
使用 visualize，製作課堂列表→詳情→請假→成功→紀錄的可點擊草稿。使用假資料；請假提交顯示已收到，未定規則標待確認。
```

### 3. 視覺探索｜imagegen

- **可用狀態：** 本工作環境可用
- **你先提供：** 品牌色＋參考圖＋用途
- **你要核對：** 輸出是點陣圖；不是可編輯 UI 元件或完整 Figma 檔

**可複製指令：**

```text
使用 imagegen，製作兩款家長教育 App 的視覺情緒板：清晰、親切、可信。分別展示色彩、字體感覺及插畫方向，沿用提供的品牌限制。
```

### 4. 元件規範｜一般 AI 對話

- **可用狀態：** 不需額外 skill
- **你先提供：** 選定高保真畫面＋元件截圖
- **你要核對：** 你在設計工具建立元件；工程核對 token

**可複製指令：**

```text
根據這些畫面整理色彩用途、字級、間距、按鈕／欄位／卡片狀態表；列出不一致處，不自行改變品牌。
```

### 5. 畫面評審｜一般 AI 對話

- **可用狀態：** 可提供截圖
- **你先提供：** 畫面截圖＋目標任務
- **你要核對：** AI 無法取代實際使用者測試或量測

**可複製指令：**

```text
逐項檢查這個請假表單的資訊層級、可讀性、錯誤提示及狀態。列位置、問題、影響、建議；無法從截圖確認的事項另列。
```

### 6. 進度與清單｜Spreadsheets

- **可用狀態：** 本工作環境可用
- **你先提供：** 本工作簿＋評審紀錄
- **你要核對：** 你確認完成證據及優先級

**可複製指令：**

```text
更新這份 checklist，按會議紀錄加入負責人、狀態與阻塞；沒有證據的項目不要標完成，保留既有 ID。
```

### 7. 工程交接｜documents

- **可用狀態：** 本工作環境可用
- **你先提供：** 定稿畫面＋規格＋素材連結
- **你要核對：** 對照實際設計檔與 API，核對規格

**可複製指令：**

```text
使用 documents 建立 UI 交接文件：元件、字級、尺寸、狀態、點擊行為、文案、素材、待定事項和版本紀錄。
```

### 8. 設計評審簡報｜Presentations

- **可用狀態：** 本工作環境可用；需要匯報時用
- **你先提供：** 視覺方向＋取捨＋待決問題
- **你要核對：** 你選最終方向；不將 AI 喜好當成使用者證據

**可複製指令：**

```text
使用 Presentations，把兩個視覺方向整理成評審簡報；用相同頁面比較可讀性、品牌一致性及維護成本。
```

### 9. 重用交接模板｜template-creator:template-creator

- **可用狀態：** 完成一次交接後再用
- **你先提供：** 已確認的交接文件或試算表
- **你要核對：** 這是可重用文件模板；不是 UI 元件庫

**可複製指令：**

```text
以這份已確認的交接文件建立可重用模板，保留章節、狀態表和檢查項目，讓下一個功能沿用。
```

### 10. Figma 整合｜Figma plugin（非 skill）

- **可用狀態：** 本對話尚未安裝／連接
- **你先提供：** 待你連接並提供指定檔案
- **你要核對：** 未核實讀寫能力，不能承諾自動建立或修改元件

**可複製指令：**

```text
若要直接處理 Figma，先連接插件並檢查它當時支援的操作，再指定檔案與工作範圍。
```
